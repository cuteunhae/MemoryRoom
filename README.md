# 도시 속 빛나는 존재

현재 구현 범위는 도시 외부 맵과 보행, 사진관·학교·집의 임시 실내 출입입니다. 오각형 프레임·섬 해안선, 순환도로·방사형 도로·굽은 골목, 일반 건물 30개, 주요 장소 5곳과 랜드마크 4곳을 임시 도형으로 표시합니다. 실내는 벽·바닥·출구만 있는 빈 공간입니다.

## 실행 방법

1. VS Code에서 **터미널 → 새 터미널**을 엽니다. 프로젝트 폴더에서 `node server.cjs`를 실행합니다.
2. Edge 또는 Chrome에서 **http://127.0.0.1:8000**을 엽니다.
3. 방향키 `↑` `↓` `←` `→`로 이동합니다. 두 방향키를 함께 누르면 대각선으로 이동합니다. 시작 위치는 논리 좌표 `(500, 450)`, 픽셀 좌표 `(4500, 4050)`입니다.
4. 사진관·학교의 입구 또는 집 뒤편 쪽문 가까이에서 **문을 왼쪽 클릭**하면 실내로 들어갑니다. 문 앞에서는 클릭 안내가 나타납니다.
5. 실내의 **나가기** 문 가까이에서 문을 클릭하면 들어왔던 입구 앞의 안전한 위치로 돌아옵니다.

게임 화면은 여백 없이 브라우저 창을 채우며, 창 크기를 바꾸면 자동으로 맞춰집니다.

지도 데이터를 별도 파일로 분리하여 프로젝트 규칙에 따라 로컬 서버 방식으로 실행합니다. Node.js가 필요하며, 추가 패키지 설치나 인터넷 연결은 필요하지 않습니다. 서버를 종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.

코드를 수정한 뒤 파일을 저장하고 브라우저를 새로고침하면 변경 사항이 반영됩니다.

## 파일

- `index.html`: 게임 화면과 스크립트 로딩
- `style.css`: 화면 스타일
- `city-data.js`: 도로 좌표·폭, 해안선, 건물, 랜드마크, 출입문·접근 지점, 임시 실내와 출입 설정
- `game.js`: 그리기, 입력, 이동 가능 영역, 충돌, 카메라, 문 클릭과 맵 전환
- `server.cjs`: 로컬 실행 서버
- `verify-city.cjs`: 실제 이동 판정으로 길 연결을 검사하는 스크립트
- `verify-interiors.cjs`: 문 클릭·잠금·실내 이동·퇴장 위치·카메라를 검사하는 스크립트

현재 위치는 저장하지 않으며 새로고침하면 중앙에서 시작합니다.

## 월드 크기와 이동 속도 조절

`game.js` 상단의 `settings` 값을 수정하고 저장한 뒤 브라우저를 새로고침합니다.

```js
const settings = {
  worldScale: 9,
  locationScale: 15,
  cameraZoom: 1,
  playerSpeed: 630,
};
```

- `worldScale`: 장소 중심·도로·해안선·시작 위치에 곱할 배율입니다. 기본값 `9`는 9000×8100픽셀 월드입니다.
- `locationScale`: 원본 장소 도형의 가로·세로에 곱할 배율입니다. 기본값 `15`는 이전 장소 크기(배율 3)의 5배입니다. 장소 크기와 월드 크기는 독립적으로 조절합니다.
- `cameraZoom`: 화면 확대 배율입니다. 기본값 `1`은 캐릭터와 배경을 원래 크기로 보여줍니다. 캐릭터의 실제 크기와 충돌 범위는 그대로입니다.
- `playerSpeed`: 초당 월드 이동 픽셀 수이며 현재 630입니다.
- 캐릭터 크기는 유지하고 화면은 브라우저 창 크기에 맞춥니다. 카메라는 확장된 월드 안에서 플레이어를 따라가며, 화면 끝이 월드 경계에 닿으면 멈춥니다.

## 확인 방법

- 방향키로 이동하면 배경이 플레이어를 따라 움직입니다. 도시 끝에서는 화면 이동이 멈춥니다.
- 도로 밖 잔디, 바다, 건물, 랜드마크 장애물로 이동하면 발밑 기준으로 멈춥니다. 도로 테두리의 밝은 선은 장식이며 회색 바닥이 보행 구역입니다.
- 놀이공원·놀이터는 바닥 전체를 자유롭게 걸을 수 있으며, 들어가도 야외 맵을 유지합니다.
- 사진관은 남서쪽에서 이어지는 길, 학교는 남쪽 진입로, 놀이공원은 서쪽 진입로, 놀이터는 남서쪽 진입로로 접근합니다.
- 집의 남쪽 정문은 가까이에서 눌러도 잠금 안내만 나오며 입장되지 않습니다. 뒤편의 좁은 골목 `R16`을 통해 북쪽 쪽문으로 들어가고, 퇴장할 때도 같은 쪽문 앞으로 나옵니다.
- 실내에서 방향키로 벽에 접근하면 멈춥니다. 출입은 걷기만으로 발생하지 않고 문을 클릭해야 합니다. 먼 곳에서 문을 클릭하면 가까이 이동하라는 안내가 나옵니다.
- 사진관·학교·집을 반복해서 드나들어도 각각 들어왔던 문 앞으로 돌아옵니다. 단서를 먼저 확인할 필요는 없습니다.
- 장소명은 기본 화면에 표시하지 않습니다. 위치 검증이 필요하면 `city-data.js`에서 `debug: false`를 `debug: true`로 바꾸고 새로고침합니다. 검증 후 다시 `false`로 되돌립니다.
- 터미널에서 `node verify-city.cjs`를 실행하면 도로 연결과 충돌을 검사합니다. 시작점에서 5개 장소 및 집 양쪽 문 앞까지의 경로, 쪽문 골목의 필요 여부, 주요 건물 3개와 일반 건물 30개의 도로 겹침을 확인합니다. 겹침 검사에는 건물 그림자와 도로 테두리도 포함됩니다.
- `node verify-interiors.cjs`는 세 장소의 왕복 출입, 집 정문 잠금, 퇴장 위치, 연속 클릭 방지, 실내 벽 충돌과 창 크기·줌 변화에 따른 클릭 좌표를 검사합니다.

## 임시 실내 설정

`city-data.js`의 `interiors`에서 실내 크기·색·벽 두께·출구·시작 위치를 수정할 수 있습니다. 실내는 픽셀 단위이며 도시 배율을 적용하지 않습니다.

| 장소 | 실내 크기 | 출구 |
| --- | --- | --- |
| 사진관 | 1100×800 | 남쪽 |
| 학교 1층 | 1600×1000 | 남쪽 |
| 집 | 1200×900 | 북쪽 쪽문 |

`entrances.interactDistance`는 출입 가능한 거리(기본 100픽셀), `clickPadding`은 문 클릭의 여유 범위(12픽셀), `cooldownMs`는 연속 클릭으로 즉시 재전환되는 것을 막는 시간(250밀리초)입니다. 실내가 창보다 작으면 가운데에 표시하고, 크면 카메라가 플레이어를 따라갑니다. 이 값들은 허용된 임시 값이며 `TODO` 주석으로 표시했습니다.

| 장소 | 논리 좌표 | 배율 9의 픽셀 좌표 | 임시 색 |
| --- | --- | --- | --- |
| 사진관 | (170, 565) | (1530, 5085) | 갈색 |
| 학교 | (265, 305) | (2385, 2745) | 황토색 |
| 놀이공원 | (774, 345) | (6966, 3105) | 살구색 |
| 놀이터 | (809, 571) | (7281, 5139) | 연노랑 |
| 집 | (533, 778) | (4797, 7002) | 회청색 |

도시 원본 데이터는 기획서의 1,000×900 논리 좌표를 유지하며, 실제 월드 크기는 배율 9를 적용한 9000×8100픽셀입니다. 장소의 `x`, `y`는 기획서 대표점이며 개발자 표시에도 이 좌표가 나옵니다. 실제 도형을 옮길 때는 `offset`을 사용합니다. 대표점을 제외한 지형·도로·일반 건물·랜드마크·문 위치는 사용자가 허용한 임시 배치입니다.

집은 대표점 `(533, 778)`을 유지하고 원본 크기를 `82×62`에서 `76×52`로 조정했습니다. `offset: { x: -8, y: -6 }`으로 실제 건물 중심을 `(525, 772)`에 둡니다. 그리기·충돌·문 위치 모두 이 실제 영역을 사용합니다. 사진관·학교는 건물 크기를 유지하고 진입로 `R07`, `R08`의 끝을 짧게 조정하여 둥근 도로 끝이 건물에 겹치지 않게 했습니다.

## 도로 좌표 수정

`city-data.js`의 `roads`에서 각 도로를 수정합니다.

```js
{ id: "R02", kind: "branch", width: 22, points: [[500, 450], [390, 405]] }
```

- `points`: 도로 중심선이 지나가는 좌표 목록입니다. 점을 추가하면 꺾이는 길을 만들 수 있습니다.
- `width`: 보행 가능한 도로 폭입니다. 논리 폭 22는 현재 배율에서 198픽셀입니다.
- `kind`: `ring`은 순환도로, `branch`는 방사형 도로, `street`는 일반 도로, `alley`는 골목입니다.
- 연결할 도로의 좌표를 일치시키거나 도로 폭이 겹치게 배치합니다. 그림과 보행 판정은 같은 데이터를 사용합니다.
- 주요 장소 크기나 문 위치를 바꾸면 연결 도로와 `accessPoints`도 맞춘 뒤 `node verify-city.cjs`로 다시 확인합니다.

랜드마크는 `landmarks`에서 변경합니다. 현재 분수대 `(210, 670)`, 시계탑 `(335, 382)`, 연못 `(585, 260)`, 큰 나무 `(698, 570)`에 배치했습니다.
