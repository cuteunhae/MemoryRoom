# 도시 속 빛나는 존재

현재 구현 범위는 임시 도시 맵, 장소 5곳 배치, 방향키 이동과 플레이어를 따라가는 화면입니다. 장소 입장과 실내 맵 전환은 다음 작업입니다.

## 실행 방법

1. 프로젝트 폴더의 `index.html`을 더블클릭합니다.
2. Edge 또는 Chrome에서 열면 도시 중앙 `(500, 450)`에 플레이어가 나타납니다.
3. 방향키 `↑` `↓` `←` `→`로 이동합니다. 두 방향키를 함께 누르면 대각선으로 이동합니다.

별도 설치, 인터넷 연결, 개발 서버가 필요하지 않습니다. HTML 파일이 편집기로 열리면 파일을 우클릭하고 **연결 프로그램 → Microsoft Edge 또는 Google Chrome**을 선택합니다.

코드를 수정한 뒤 파일을 저장하고 브라우저를 새로고침하면 변경 사항이 반영됩니다.

## 파일

- `index.html`: 게임 화면과 조작 안내
- `style.css`: 화면 스타일
- `game.js`: 도시 배치, 임시 캐릭터, 입력, 이동, 카메라, 건물·해안 충돌 처리

플레이어 속도는 `game.js`의 `player.speed`에서 조정합니다. 기본값은 초당 210픽셀입니다. 현재 위치는 저장하지 않으며 새로고침하면 중앙에서 시작합니다.

## 확인 방법

- 방향키로 이동하면 배경이 플레이어를 따라 움직입니다. 도시 끝에서는 화면 이동이 멈춥니다.
- 사진관·학교·집의 색 블록과 바다 쪽으로 이동하면 발밑 기준으로 멈춥니다.
- 놀이공원·놀이터의 색 구역과 도로 밖의 땅은 자유롭게 걸을 수 있습니다.
- 장소명은 기본 화면에 표시하지 않습니다. 위치 검증이 필요하면 `game.js`에서 `debug: false`를 `debug: true`로 바꾸고 새로고침합니다. 검증 후 다시 `false`로 되돌립니다.

| 장소 | 대표 좌표 | 임시 색 |
| --- | --- | --- |
| 사진관 | (170, 565) | 갈색 |
| 학교 | (265, 305) | 황토색 |
| 놀이공원 | (774, 345) | 살구색 |
| 놀이터 | (809, 571) | 연노랑 |
| 집 | (533, 778) | 회청색 |

도시 크기는 기획서의 1,000×900이며, 장소 도형의 중심을 대표 좌표에 맞췄습니다. `city` 설정에 있는 도형 크기·색·해안선·도로·시작 위치는 허용된 임시 값입니다. 현재 도로는 보행을 안내하는 그림이며 도로 밖의 땅에도 이동 제한이 없습니다.
